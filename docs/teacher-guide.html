URBAN TRAIL · 선생님용 수업 안내

서버·로그인 없이 태블릿에서 바로 사용 · PIN 없음

1. 이 프로그램을 이렇게 활용하세요

  • 수업 전: 각 팀 태블릿에서 이 파일을 엽니다. 인터넷이 없어도 됩니다. 선생님 설정에서 플레이 시간(기본 15턴)·재도전·특별 칸만 필요하면 바꿉니다.
  • 한 대 = 한 팀: 모둠은 태블릿 한 대를 같이 쓰고 돌아가며 주사위를 굴립니다. 개인 활동이면 「혼자 하기」로 바로 시작하세요.
  • 선생님 역할: 사용법을 짧게 보여 주고, 교실을 돌며 화면을 확인하며, 끝나면 제출용 PDF를 거둡니다. 기기끼리 결과가 자동으로 모이지 않습니다.

2. 학생에게 이렇게 안내하세요

수업 시작 때 따라 말하기

  1. 「지도 보기는 트레일 맵, 주사위 게임은 어반 런, 스탬프 모으기는 트레일 로그예요.」
  2. 「오늘은 어반 런 시작을 누릅니다. 친구와 함께인지, 혼자 하기인지 고르세요.」
  3. 「학급과 팀 이름, 친구 이름을 적고 여행 말을 고르면 보드가 나와요.」
  4. 「화면에 지금 주사위가 적힌 친구가 굴립니다. 도착한 도시 카드를 소리 내어 읽고, 랜드마크 미션은 상의해서 답하세요.」
  5. 「턴이 끝나면 성찰을 적고, 노란 버튼 제출용 PDF 저장을 눌러 선생님께 제출합니다.」
처음 쓰는 반이라면 홈의 화면 안내를 프로젝터로 한 번 같이 넘겨 보세요.

3. 수업 중 활동 아이디어

  • 도시 카드 함께 읽기: 한 명이 위치·기후를 읽고, 다른 친구가 대륙을 맞혀 보게 합니다.
  • 미션은 상의 후 한 번만: 답을 고르기 전에 카드의 산업·랜드마크를 근거로 말하게 합니다.
  • 지도로 다시 찾기: 상단 트레일 맵에서 방금 간 도시를 확대·검색하거나, 도시 비교로 인구·기후를 나란히 봅니다.
  • 마무리 발표: 각 팀이 인상 깊었던 도시와 이유를 한 문장으로 말합니다. 리포트 Q1을 그대로 쓰면 됩니다.

4. 50분 수업 흐름 예시

시간선생님학생
5분화면 안내·세 메뉴 소개같이 보며 버튼 위치 확인
5분팀 편성·태블릿 배부 확인어반 런 → 팀 정보 입력
25~30분순회하며 읽기·상의 독려주사위·도시 카드·미션
7분PDF 저장 방법 안내성찰 작성 · 제출용 PDF 저장
5분인상 깊은 도시 발표한 문장 공유

시간이 짧으면 선생님 설정에서 빠른 탐험(8턴)으로 바꿉니다.

5. 결과 확인

리포트의 제출용 PDF 저장 → 인쇄 창에서 「PDF로 저장」.
파일명 예: URBAN_TRAIL_학급_팀이름_날짜.pdf
수업 중에는 각 태블릿 화면을 눈으로 확인해도 됩니다. 기기 기록은 그 태블릿에만 남습니다.
