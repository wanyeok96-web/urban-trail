§1현황 진단

1.0을 실제로 15턴(기본 탐험) 완주시켜 측정한 결과를 근거로 한다.

학습 범위가 주사위에 종속된다

기본 탐험 1회를 완주하면 방문 도시는 11곳, 스탬프는 10개였다. 데이터로 준비된 48개 도시 중 약 23%다. 나머지 37개 도시는 학생이 존재조차 모른 채 수업이 끝난다. 게다가 보드에 오르는 도시 자체가 매 게임 24개로 제한되므로, 절반은 아예 후보에도 없다.

혼자서는 시작할 수 없다

설정 2단계가 학생 이름 2명 이상을 요구한다. 결석·홀수 인원·개별 학습 시간·가정 복습 — 1인 상황 전체가 진입 불가다.

지도가 정보를 담지 않는다

보드 중앙 지도는 현재 위치를 표시할 뿐 클릭할 수 없고, 도감은 격자 목록이라 “이 도시가 지구의 어디쯤인가”라는 가장 기본적인 공간 감각이 생기지 않는다. 도시 정보에 닿는 경로가 ‘게임에서 도착하기’ 하나뿐이다.

문제는 기능이 모자란 것이 아니라, 게임의 우연성과 학습의 체계성이 한 통로에 묶여 있다는 것이다.

우연은 게임을 재미있게 만들지만 커리큘럼을 만들지는 못한다. 두 가지를 분리하고, 보상 체계로 다시 연결하는 것이 2.0의 뼈대다.

§22.0의 구조 — 세 개의 축

화면을 늘리는 개편이 아니라, 진입점을 셋으로 정리하는 개편이다. 시작 화면은 6개 버튼 나열에서 세 개의 큰 선택지로 바뀐다.

신규 · 핵심

월드 아틀라스

정밀 세계지도 위 48개 도시 핫스팟. 게임과 무관하게 언제나 전체 도시에 접근한다. 도감을 흡수해 지도 뷰와 목록 뷰를 오간다.

기존 · 확장

보드게임

모둠 플레이는 그대로 두고 혼자 플레이를 추가한다. 여행 목표 카드를 넣어 1인전에도 방향성을 준다.

기존 · 통합

나의 여권

게임 한 판을 넘어 누적되는 개인 기록. 수집률·최고 기록·모둠 결과를 한곳에서 본다.

세 축을 잇는 것 the hinge

핵심 연결 장치는 스탬프 하나다. 게임에서 랜드마크 미션에 성공해도, 아틀라스에서 도시를 읽고 퀴즈를 풀어도 같은 스탬프가 같은 여권에 쌓인다. 이 규칙 하나로 “집에서 지도 보며 공부한 것”이 “수업 시간의 게임”과 같은 화폐가 된다. 아틀라스가 게임의 곁가지가 아니라 대등한 통로가 되는 지점이다.

§3월드 아틀라스

신규 화면이자 이번 개편의 무게중심.

지도 엔진 map

  • 정밀도 — 현재 17개 개략 폴리곤(대륙당 8~30점)을 대륙당 60~120점 수준으로 다시 그린다. 반도·만·섬의 형태가 식별 가능한 수준이 목표.
  • 도법 — 등장방형(equirectangular) 유지. 위경도 → 화면 좌표 변환이 단순해 핫스팟 좌표를 데이터에서 그대로 쓸 수 있다.
  • 확대·이동 — SVG viewBox를 조작한다. 휠 줌, 드래그 팬, 더블클릭 줌, 권역 버튼으로 자동 프레이밍. 터치 드래그와 ＋／－ 버튼도 지원(태블릿·모바일).
  • 축척 3단계 — 전 세계에서는 점만, 권역 축척에서는 도시명 라벨, 도시 축척에서는 랜드마크 아이콘과 국가명까지 단계적으로 드러낸다.
  • 폴백 — 기존 개략 지도를 그대로 남겨, 정밀 데이터 작업이 끝나지 않은 대륙도 항상 표시되게 한다.

핫스팟 hotspot

  • 상태 3종 — 미발견(작은 회색 점) / 발견(권역 색) / 스탬프 획득(금색 이중 원).
  • 호버 시 도시명·국가 툴팁, 클릭 시 우측 상세 패널. 좁은 화면에서는 하단 시트로 올라온다.
  • 미발견 도시도 열람 가능하게 한다. 아틀라스는 게임 보상이 아니라 학습 자료이기 때문이다. 다만 교사 설정에 미발견 도시 잠금 스위치를 두어, 수집 동기를 강조하고 싶은 교사가 선택할 수 있게 한다(기본 꺼짐).
  • 키보드 접근 — Tab으로 핫스팟 순회, Enter로 열기. 지도를 못 쓰는 상황을 위해 목록 뷰 토글을 항상 제공한다.

도시 상세 패널 detail

기존 도시 카드의 7개 항목을 5개 탭으로 재편해, 한 번에 읽는 양을 줄이고 비교 학습이 쉬워지게 한다.

이미지 갤러리 media

도시당 1~4장. 표시 우선순위는 로컬 파일 → 외부 URL → 대체 카드다. 개별 이미지가 실패하면 조용히 빼고 나머지를 보여주며, 전부 실패하면 지금과 같은 대체 카드로 떨어진다. 이미지가 하나도 없어도 프로그램은 완전히 동작한다는 1.0의 원칙은 그대로다.

  • 출처 표기 필드(credit)를 필수로 둔다. 위키미디어 공용의 CC 라이선스 자료를 우선 수집한다.
  • 교사 설정에 외부 이미지 불러오기 스위치를 둔다. 외부 접속이 차단된 학교망에서는 꺼두면 로컬 파일과 대체 카드만 쓴다.

§4혼자 플레이

수업 중 1인 1기기와 가정 예습·복습, 두 상황을 모두 지원한다. 앞은 50분 안에 끝나고 교사가 결과를 걷을 수 있어야 하고, 뒤는 반복해도 질리지 않을 장기 목표가 있어야 한다.

진입 조건 완화 minimum

  • 학생 이름 최소 인원을 2명에서 1명으로 낮춘다.
  • 설정 1단계에 모둠 플레이 / 혼자 플레이 선택을 추가한다. 혼자 플레이를 고르면 이름 입력이 1칸으로 시작한다.
  • 1인일 때 UI 문구를 바꾼다. “이번 차례 · 김지호” → “김지호의 여행”. 차례를 넘기는 개념이 없으므로 순번 표시도 감춘다.
  • 리포트의 ‘모둠명’은 ‘여행자명’으로 자동 전환한다.

여행 목표 카드 goals

1인전은 경쟁 상대가 없어 동기가 약해진다. 게임 시작 시 목표 카드 3장을 무작위로 제시해 “무엇을 노리고 굴릴 것인가”를 만든다. 모둠전에도 그대로 적용해 두 모드의 규칙을 통일한다.

목표 판정에는 좌표·인구·해발 같은 수치 데이터가 필요하다. §5의 데이터 확장이 이 기능의 전제가 된다.

수업 중 1인 1기기 — 결과 수합 classroom

기기가 6대에서 30대로 늘면 “저장된 결과 비교” 화면만으로는 부족하다. 학생 손을 거쳐 교사에게 도달할 경로를 만든다.

  • 결과 요약 코드 — 리포트에서 한 줄 텍스트를 복사한다. 예: 1-3 | 김지호 | 445점 | 스탬프10 | 권역1. 학생이 구글 설문·패들렛·클래스룸에 붙여넣으면 교사가 표로 취합할 수 있다.
  • 기존 텍스트 파일 저장·인쇄 기능은 그대로 두어, 네트워크 없이 종이로 걷는 운영도 가능하게 한다.
  • 교사 설정에 세션 코드(예: 0817-3반)를 입력해 두면 모든 결과에 자동으로 붙어, 반별 취합이 쉬워진다.

가정 학습 — 누적되는 여권 at home

  • 수집률을 1급 지표로 올린다. “48개 도시 중 12개 발견 · 스탬프 8개”가 시작 화면에 항상 보인다.
  • 개인 기록 — 최고 점수, 최다 스탬프, 최다 권역 완성, 누적 플레이 횟수. 판마다 리셋되지 않는다.
  • 오늘의 도시 — 접속할 때마다 아직 발견하지 않은 도시 하나를 추천한다. 하루 3분짜리 복습 습관을 만드는 장치.
  • 아틀라스 미션으로 얻은 스탬프도 같은 여권에 쌓이므로, 게임을 하지 않는 날에도 진도가 나간다.

§5데이터 모델 확장

기존 필드는 하나도 버리지 않고 세 묶음을 더한다. 수치 필드가 생기면 목표 카드 판정, 정렬·필터, 기후 그래프, 도시 비교가 한꺼번에 가능해진다. 

// 기존 필드(city, country, climate, industry …)는 그대로 두고 추가
{
  images: [
    { src: "assets/cities/seoul-01.jpg",
      caption: "경복궁 근정전", credit: "직접 촬영" },
    { src: "https://upload.wikimedia.org/…/Seoul_skyline.jpg",
      caption: "한강과 도심", credit: "Wikimedia Commons, CC BY-SA 4.0" }
  ],

  stats: {                      // 목표 카드 판정 · 정렬 · 그래프의 근거
    population:  9500000,       // 숫자 (기존 populationScale은 문장으로 유지)
    elevation:   38,            // 해발 m
    climateZone: "Dwa",          // 쾨펜 기후 구분
    tempJan: -2.4, tempJul: 25.7,  // °C
    annualRain:  1400           // mm
  },

  functions: ["수도", "금융", "문화"],   // 도시 기능 유형(필터·목표 판정용)
  related:   ["tokyo", "beijing"]        // 비교하면 좋은 도시 추천
}

파일 구조 refactor

script.js는 이미 207KB다. 이미지 배열과 수치가 붙으면 300KB를 넘고, 교사가 도시 내용을 직접 고치기도 어려워진다. 도시 데이터만 data.js로 분리할 것을 제안한다 — 빌드 도구 없이 <script> 태그 하나를 더 얹는 것이므로 “빌드 없음” 원칙은 유지된다.

§8지킬 것과 걱정할 것

1.0에서 그대로 가져가는 원칙 constraints

빌드 도구 없음
HTML · CSS · Vanilla JS. data.js 한 개만 추가한다.
서버 · 로그인 없음
모든 기록은 localStorage에만. 학생 이름은 기기 밖으로 나가지 않는다.
외부 지도 API 없음
세계지도는 SVG로 직접 그린다. 정밀도만 올린다.
이미지는 있으면 좋은 것
한 장도 없어도 모든 기능이 동작한다.
실시간 통신 없음
모둠 간 연결·거래는 계속 만들지 않는다.
PC · 태블릿 우선
Chrome · Edge 기준, 모바일에서도 핵심 기능 동작.

위험 요소와 대응 risk

위험대응
외부 이미지 링크가 깨지거나 학교망에서 차단 개별 실패는 조용히 제외, 전체는 교사 설정에서 끄기. 핵심 도시는 로컬 파일을 우선 확보한다.
정밀 지도 좌표 작업량 대륙 단위로 나누어 진행하고, 미완성 대륙은 기존 개략 폴리곤을 그대로 쓴다. 지도가 절대 비지 않는다.
이미지 저작권 credit 필드를 필수로 하고 상세 패널에 항상 노출. 위키미디어 CC 자료를 우선 수집한다.
아틀라스가 게임을 대체해 버림 아틀라스 미션 스탬프는 게임과 같은 값이되, 권역 완성 보너스와 목표 카드는 게임에서만 얻게 해 역할을 나눈다.
기능이 늘어 첫 화면이 복잡해짐 진입점을 3개로 고정한다. 새 기능은 반드시 세 축 중 하나에 소속시키고, 시작 화면 버튼은 늘리지 않는다.
