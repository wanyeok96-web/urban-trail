    이렇게 플레이해요

    세 가지 길을 알아 두세요
    트레일 맵은 세계 지도에서 도시 학습 대시보드로 탐험하고, 어반 런은 주사위 보드게임이며, 트레일 로그는 모은 스탬프를 보는 기록장입니다.
    어반 런으로 여행을 시작해요
    홈에서 어반 런을 누릅니다. 친구와 함께는 학급·팀 이름·친구 이름(2~5명)을 적고, 혼자 하기는 학급과 이름만 입력하면 바로 시작됩니다.
    친구들이 돌아가며 주사위를 굴립니다
    한 번 굴릴 때마다 1턴이 줄어듭니다. 화면에 지금 주사위가 적힌 친구가 굴리세요.
    도착한 도시 학습 대시보드를 함께 읽습니다
    위치·기후·인구·산업·문화를 소리 내어 읽습니다. 처음 방문하면 +10점.
    랜드마크 미션에 도전합니다
    정답이면 +30점과 스탬프. 틀려도 힌트를 보고 한 번 더 도전할 수 있습니다(재도전 정답 시 +15점과 스탬프).
    특별 칸·출발·권역 보너스
    특별 칸 이벤트, 출발 통과 +20 / 정지 +40, 같은 권역 도시 4곳 완성 시 +60점과 배지.
    끝나면 PDF로 제출합니다
    성찰을 적은 뒤 제출용 PDF 저장을 눌러 선생님께 전달하세요.

    점수 안내

    도시 첫 방문 +10 · 미션 정답 +30(스탬프) · 재도전 정답 +15(스탬프) · 출발 통과 +20 · 출발 정지 +40 · 권역 완성 +60 · 특별 칸 +10~30
    이미 스탬프를 받은 도시에 다시 도착하면 재방문 보너스(+5)를 받고 다음 친구에게 순서가 넘어갑니다.

    선생님은 사용법을 안내하고, 수업 중 활동을 이끌며, 결과(PDF)를 확인하시면 됩니다. 서버·로그인 없이 태블릿에서 바로 사용합니다.

    1. 이 프로그램을 이렇게 활용하세요

    수업 전에 한 번만 준비
    각 팀 태블릿에서 이 파일을 엽니다. 인터넷이 없어도 됩니다. 아래 선생님 설정에서 플레이 시간(기본 15턴)·재도전·특별 칸만 필요하면 바꿉니다.
    한 대 = 한 팀 (또는 혼자 하기)
    모둠은 태블릿 한 대를 같이 쓰고, 친구들이 돌아가며 주사위를 굴립니다. 개인 활동이면 혼자 하기로 학급·이름만 입력하고 바로 시작할 수 있습니다.
    선생님의 역할
    사용법을 짧게 보여 주고, 교실을 돌며 화면을 확인하며, 수업이 끝나면 제출용 PDF를 거둡니다. 기기끼리 결과가 자동으로 모이지 않습니다.

    2. 학생에게 이렇게 안내하세요

    수업 시작 때 따라 말하기

    1. 홈 화면의 세 가지를 가리킵니다. 「지도 보기는 트레일 맵, 주사위 게임은 어반 런, 스탬프 모으기는 트레일 로그예요.」
    2. 「오늘은 홈의 어반 런을 누릅니다. 친구와 함께인지, 혼자 하기인지 고르세요.」
    3. 「학급과 팀 이름, 친구 이름을 적고 여행 말을 고르면 보드가 나와요.」
    4. 「화면에 지금 주사위가 적힌 친구가 굴립니다. 도착한 도시 학습 대시보드를 소리 내어 읽고, 랜드마크 미션은 상의해서 답하세요.」
    5. 「턴이 끝나면 성찰을 적고, 노란 버튼 제출용 PDF 저장을 눌러 선생님께 제출합니다.」
    처음 쓰는 반이라면 홈의 💡 튜토리얼을 프로젝터로 한 번 같이 넘겨 보세요.

    3. 수업 중 활동 아이디어

    도시 학습 대시보드 함께 읽기
    한 명이 위치·기후를 읽고, 다른 친구가 「이 도시는 어느 대륙일까?」를 맞혀 보게 합니다. 정보를 읽지 않고 미션만 풀면 학습 효과가 떨어집니다.
    미션은 상의 후 한 번만
    답을 고르기 전에 팀에서 근거를 말하게 합니다. 「대시보드에 나온 산업·랜드마크를 보고 고르자」고 안내하세요.
    지도로 다시 찾기
    게임 중간에 상단 트레일 맵으로 가서, 방금 방문한 도시를 누르면 게임과 같은 도시 학습 대시보드가 열립니다. 자연·인문·이야기 탭과 미션으로 다시 학습하게 하세요. 도시 비교로 인구·해발·기후를 나란히 보게 할 수도 있습니다.
    마무리 발표 (3~5분)
    각 팀이 「가장 인상 깊었던 도시 한 곳」과 이유를 한 문장으로 말합니다. 리포트 Q1에 적은 내용을 그대로 활용하면 됩니다.

    4. 50분 수업 흐름 예시

    시간선생님학생
    5분튜토리얼·세 메뉴 소개같이 보며 버튼 위치 확인
    5분팀 편성·태블릿 배부 확인어반 런 → 팀 정보 입력
    25~30분순회하며 읽기·상의 독려주사위·도시 학습 대시보드·미션
    7분PDF 저장 방법 한 번 더 안내성찰 작성 · 제출용 PDF 저장
    5분인상 깊은 도시 발표 진행한 문장 공유

    시간이 짧으면 선생님 설정에서 빠른 탐험(8턴)으로 바꿔 주세요. 기본은 15턴입니다.

    5. 결과는 이렇게 확인하세요

    권장: 제출용 PDF

    리포트 화면의 노란 버튼을 누르면 인쇄 창이 열립니다. 「PDF로 저장」을 고르면 파일명이 URBAN_TRAIL_학급_팀이름_날짜.pdf로 붙습니다. 클래스룸·공유 폴더·USB로 거두면 됩니다.

    수업 중에는 각 태블릿 화면을 눈으로 확인하셔도 됩니다. 이 기기에 저장된 여행 기록은 그 태블릿에 남은 기록만 보이며, 반 전체가 한곳에 모이지 않습니다.

    이 기기의 이용자 정보

    학생 또는 선생님을 고르고, 학교·학년·반·이름을 적어 두세요. 다음 여행 준비 때 불러올 수 있습니다.

    이 기기 소리

    주사위·버튼·정답·스탬프 효과음을 켜고 음량을 맞춥니다. 배경음악은 없습니다. 설정은 이 기기에만 저장됩니다.

    30%

    개인정보 안내

    입력한 학교·학년·반·이름과 학습 기록은 이 기기의 브라우저에만 저장됩니다. 인터넷으로 서버에 보내지 않으며, 다른 태블릿과 자동으로 공유되지 않습니다.

    선생님 도구

    교사용 설정과 이 기기에 남은 여행 결과를 열 수 있습니다.

    50분 수업 운영 예시

    도입 5분(게임 소개·팀 편성) → 설정 5분(팀 정보·말 선택) → 플레이 25~30분(기본 탐험 15턴) → 리포트·PDF 저장 7분 → 마무리 5분(인상 깊은 도시 발표).
    태블릿 한 대당 한 팀이며, 친구들이 돌아가며 주사위를 굴립니다. 학생은 제출용 PDF를 저장하고, 선생님은 각 기기의 PDF 또는 이 기기에 저장된 여행 기록으로 확인하세요. 기기끼리 자동 합산되지 않습니다.
